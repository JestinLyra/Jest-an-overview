# Jest — Life Tracker

A mobile-first personal tracker for:

- shopping and spending (online/in-store, cards, budgets, deliveries, potential nurse-related tax deductions)
- sleep and mood (monthly combined vertical grid; annual separate views)
- menstruation and symptoms
- monthly water + sugar wheel dashboard

Data is stored locally in the browser using `localStorage`.

## Run
Open `index.html` or serve the folder with any static web server.

## Notes
Tax-deductible flags are for personal organisation only and are not tax advice. Actual deductibility depends on ATO rules and the user's circumstances.
